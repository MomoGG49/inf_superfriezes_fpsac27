
In this repository we include sage code to help the reader compute examples of super lambda and mu-expansions, since doing it by hand is a tedious and difficult task. 

The sage code is based in the Exterior Algebra class of the Clifford Algebra package in sage (https://doc.sagemath.org/html/en/reference/algebras/sage/algebras/clifford_algebra.html#sage.algebras.clifford_algebra.ExteriorAlgebra). Even variables are elements in a polynomial ring over the rational numbers. We did not implement the square root operation, so all the generators in the algebra of even variables are the **square roots** of the usual even generators. 

*Example*: Consider the super algebra generated by 3 even variables and 2 odd variables, we defined this as:
```sage
P = PolynomialRing(QQ, 3, ['x1', 'x2', 'x_3'])
P.inject_variables()
P = FractionField(P)
#We will work with the exterior algebra over the odd variables
F.<T1,T2> = ExteriorAlgebra(P)
```

Thus, the output 

$$(\frac{-x_1}{x_2^2x_3})T_1T_2$$ 

should be read as 

$$(\frac{-\sqrt{x_1}}{x_2 \sqrt{x_3}})T_1T_2.$$

## Contents if this repository
Besides this README.md file, the repository contains 3 files, one for each subsection of section 3 in the submission. 

### File 1: Holonomy. 
This is an auxiliar file to compute the entries of the holonomy matrices asocaited to the polygons $P_i^x$ for the decorated triangulation in Figure 7. The code includes the definition of the basic holonomy matrices, and the product of which give the matrix $H_{\rho}$ of Theorem 2.7. To see how to find the right product to compute, see [^1]. 


### File 2: Solutions-superfrieze.

This file has algorithms to generate and find solutions of the realization problem with 2 odd generators for the A(1,n) marked point annulus. It automatically produces the associated quadratic system and then proceeds to check whether the Gröebner basis of the ideal generated by this equations contains 1. If it does, then the system has no solution (the variety defined by the equations is empty). Then we present the particular case of Example 3.6. A random choice of quiditty sequences is produced everytime the user compiles de code. 

### File 3: Growth-coeffs

This file provides code to compute infinite superfriezes through their quiddity sequences and the recurrence relations in Proposition 2.5.4 [^2]. We provide an example of how the straightforward analog of *growth* does not carry to the super setting. We do this via the decorated triangulation of A(1,3) presented in the extended abstract, and compute the difference between entries in its 3th even non-trivial row, and the entries directly above them, and note that they don't agree. We also do this for the other equivalence class of orientation, for which we check that the 6th non-trivial row, since this is the period of the superfrieze in that case.
